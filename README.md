# אחוזת המשכן — אתר וילה ביבנאל

אתר תדמית לוילה יוקרתית להשכרה ביבנאל, גליל תחתון.
אתר חי: [shablonishay.github.io/HaMishkan](https://shablonishay.github.io/HaMishkan/)

---

## מבנה הקבצים

```
index.html      עמוד ראשי (כל התוכן בקובץ אחד)
style.css       כל העיצוב (RTL, רספונסיבי, אנימציות)
script.js       גלריה (רשימה קבועה), מסך מלא, פס יצירת קשר, טופס זמינות, אנימציות
favicon.png     אייקון הלשונית בדפדפן
assets/
  hero.webp     תמונת הרקע של הדף הראשי (hero.jpeg = מקור)
  pool.webp     תמונת הבריכה בסקציה הייעודית (pool.jpeg = מקור)
  og-image.jpg  התמונה שמופיעה בשיתוף בווטסאפ/פייסבוק
  logo.webp     לוגו מוקטן לאתר (LOGO.png = מקור)
  gallery/      01.webp–33.webp תמונות הגלריה, לפי סדר הצגה
  gallery/thumbs/  עותקים קטנים (240px) לפס התמונות הממוזערות
```

## פרטי הנכס

- **כתובת:** טייסת הגליל, יבנאל, גליל תחתון
- **קיבולת:** עד 70 אורחים
- **חדרי שינה:** 7 (מהם 4 סוויטות עם שירותים ומקלחת פרטיים)
- **שירותים:** 3 שירותים ו-2 מקלחות מרכזיים לשאר ה-3 חדרים
- **אופציה נוספת:** סוויטה חיצונית צמודה
- **כניסה:** 15:00 | **יציאה:** 11:00
- **ללא חיות מחמד**

**שירותים עיקריים:**
- בריכת שחייה ענקית ומקורה (לא מחוממת)
- ספא מחומם עם ג'קוזי ובריכת זרמים
- מטבח חיצוני מלא + מנגל
- חניה חינמית עם נוף
- 2 טלוויזיות חכמות עם HOT

## הוספת תמונות לגלריה

1. שמרו את התמונה כ־`assets/gallery/34.webp` (רוחב עד 1600px) ועותק קטן ברוחב 240px כ־`assets/gallery/thumbs/34.webp`.
2. הוסיפו שורה לרשימה `PHOTOS` בראש `script.js`, למשל `['34', 'חדר שינה'],` — המיקום ברשימה קובע את הסדר בגלריה.

התמונות עברו תיקון צבע אחיד ועדין (איזון לבן חמים, הבהרת צללים, חידוד קל) — בלי שינוי תוכן.
